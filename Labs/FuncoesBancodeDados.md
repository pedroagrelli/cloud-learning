## Trabalhar com funções

# Objetivos: 

- Usar as funções de agregação SUM(), MIN(), MAX() e AVG() para resumir dados.

- Usar a função SUBSTRING_INDEX() para dividir strings.

- Usar as funções LENGTH() e TRIM() para determinar o comprimento de uma string.

- Usar a função DISTINCT() para filtrar registros duplicados.

- Usar funções na declaração SELECT e na cláusula WHERE
