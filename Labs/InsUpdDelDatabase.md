## Inserir, atualizar e excluir dados de um banco de dados
# Demonstracao de como inserir, atualizar, excluir e importar linhas de dados usando linguagem de consulta estruturada (SQL).

# Objetivos: 
- Inserir linhas em uma tabela.

- Atualizar linhas em uma tabela.

- Excluir linhas de uma tabela.

- Importar linhas de um arquivo de backup de um banco de dados.
