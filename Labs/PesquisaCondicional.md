## Pesquisa condicional

# Demonstracao de como usar a declaração SELECT e a cláusula WHERE para filtrar registros com uma pesquisa condicional.

# Objetivos : 

Escrever uma condição de pesquisa usando a cláusula WHERE.

Usar o operador BETWEEN.

Usar o operador LIKE com caracteres coringa.

Usar o operador AS para criar um alias de coluna.

Usar funções em uma declaração SELECT.

Usar funções em uma cláusula WHERE.
