## Operações na tabela de banco de dados
# Demonstracao de como usar algumas operações comuns de banco de dados e tabelas.
# Objetivos:

Usar a declaração CREATE para criar bancos de dados e tabelas.

Usar a declaração SHOW para visualizar bancos de dados e tabelas disponíveis.

Usar a declaração ALTER para alterar a estrutura de uma tabela.

Usar a declaração DROP para excluir bancos de dados e tabelas.
